# Medidata Solutions

> Medidata Solutions (a Dassault Systemes company) provides a unified cloud platform for clinical research. Its Rave EDC system and Rave Web Services (RWS) API let external systems push, pull, and edit clinical trial data using the CDISC ODM standard. Integration is coordinated through Medidata Developer Central, with first-party Python client libraries and HTTP Basic / MAuth authentication.

## APIs

- [Rave Web Services (RWS)](https://www.medidata.com/en/clinical-trial-services/developer-central/): RESTful API for Medidata Rave EDC; exchanges clinical data, study design metadata, protocol deviations, comments, and audit-trail history as CDISC ODM (XML) or CSV. Base host pattern https://{subdomain}.mdsol.com/RaveWebServices.

## Docs

- [Developer Central](https://www.medidata.com/en/clinical-trial-services/developer-central/): membership program with RWS docs, test environment, and community forum.
- [RWS Web Help](http://rws-webhelp.s3.amazonaws.com/WebHelp_ENG/introduction/index.html): introduction and API reference for Rave Web Services.
- [rwslib documentation](https://rwslib.readthedocs.io/en/latest/): Python client library docs and getting-started guide.
- [Medidata Tech Blog](https://techblog.mdsol.com/): engineering posts including rwslib and MAuth.

## SDKs

- [rwslib (PyPI)](https://pypi.org/project/rwslib/): Rave Web Services client for Python (mdsol/rwslib, MIT).
- [requests-mauth (PyPI)](https://pypi.org/project/requests-mauth/): MAuth request-signing for the requests library (MIT).
- [mauth-client (PyPI)](https://pypi.org/project/mauth-client/): general MAuth client for Python (MIT).
- [GitHub: mdsol](https://github.com/mdsol): Medidata's open-source organization.

## Authentication

- [MAuth signing](https://techblog.mdsol.com/2015/12/08/rwslib-and-mauth.html): RSA request-signing scheme (preferred for long-lived integrations).
- HTTP Basic authentication (Rave username/password over HTTPS).
